Simple E-Commerce Website (Guest Checkout)

A simple guest-only e-commerce web application built with Next.js 15, Zustand, MongoDB Atlas, Tailwind CSS, Cloudinary for Storing Images and Stripe Checkout.  
Users can browse products, view product details, add items to cart, select items to checkout, and pay using Stripe (test mode) — no login required.

---

## 🚀 Features

- 🛍 Product listing and product details page
- ➕ Add to cart (guest-only)
- ✅ Select one or multiple items for checkout
- 🧮 Quantity control and cart total calculation
- 💳 Stripe Checkout integration (test mode)
- 🧾 Order summary before payment
- 🔐 Secure Stripe webhook to save orders
- 🎨 Responsive UI with Tailwind CSS

---

## 🧰 Tech Stack

- **Framework:** Next.js 15 (App Router)
- **State Management:** Zustand
- **Database:** MongoDB Atlas + Mongoose
- **Payments:** Stripe Checkout + Webhooks
- **Styling:** Tailwind CSS
- **HTTP Client:** Axios
- **Package Manager:** PNPM
- Cloudinary for Storing Images
